repo joelson

Repositório pacman pessoal — apps do meu desktop Hyprland, para sincronizar PC e notebook.

Configurar numa máquina nova

curl -O https://www.joelsonmendonca.com/arch-setup/joelson-repo.gpg
sudo pacman-key --add joelson-repo.gpg
sudo pacman-key --lsign-key $(curl -s https://www.joelsonmendonca.com/arch-setup/KEYID)

sudo tee -a /etc/pacman.conf <<'EOF'

[joelson]
SigLevel = Required
Server = https://www.joelsonmendonca.com/arch-setup/$arch
EOF

# habilite [multilib] no /etc/pacman.conf (steam), depois:
sudo pacman -Syu joelson-base joelson-nvidia

Dia a dia

sudo pacman -Syu
